## 커밋 자동화

기능 추가·버그 수정 작업이 검증(빌드/테스트/구문 확인 등, 프로젝트에 검증 수단이 있는
경우)을 통과하면, 사용자의 별도 요청 없이도 로컬 커밋까지는 자동으로 실행한다
(commit-and-push 스킬의 커밋 단계). 원격 푸시는 이 자동화에 포함되지 않으며 항상 사람
확인을 받는다.
